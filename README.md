# Juego del Ahorcado en PHP

Este es el clásico juego del ahorcado desarrollado en PHP. 

## Instrucciones de juego
1. El sistema seleccionará una palabra aleatoria de la lista.
2. Intenta adivinar la palabra seleccionando las letras del abecedario.
3. Si adivinas la palabra antes de agotar tus intentos, ¡ganarás la partida!
4. Si fallas demasiadas veces, el juego terminará.
